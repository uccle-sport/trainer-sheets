# Trainer sheets

React + TypeScript app built with [Vite](https://vite.dev) and [Bun](https://bun.sh). Styles are written in Less and imported directly from components (Vite compiles them).

## Scripts

- `bun install` — install dependencies
- `bun run start` (or `bun run dev`) — dev server on http://localhost:3000
- `bun run build` — type-check and build to `build/`
- `bun run preview` — serve the production build
- `bun run typecheck` — `tsc --noEmit`
- `bun run lint` — oxlint
